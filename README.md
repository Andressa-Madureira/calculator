# Calculadora 🧮
Este projeto consiste em uma calculadora funcional desenvolvida com HTML, CSS e JavaScript. Criada durante as aulas do curso DevClub, ela visa demonstrar como criar uma interface simples e eficiente para cálculos, com funcionalidades como limpar, apagar e calcular expressões matemáticas.

🛠️ Tecnologias Utilizadas
<ul>
  <li>HTML: Estrutura da página</li>
  <li>CSS: Estilização da interface com design responsivo e agradável</li>
  <li>JavaScript: Lógica de operação e manipulação da interface, como inserir números, apagar e realizar cálculos</li>
</ul>

🚀 Funcionalidades
<ul>
  <li>Inserção de números e operações</li>
  <li>Botões para limpar e apagar entradas</li>
  <li>Operação de cálculo com o botão de igual (=)</li>
</ul>

Este projeto é uma excelente demonstração de como criar funcionalidades interativas com JavaScript, além de ser uma ótima maneira de praticar a manipulação do DOM e a lógica de eventos.
